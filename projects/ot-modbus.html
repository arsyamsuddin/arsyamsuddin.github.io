OT Security: Modbus Threat Simulation

This project simulates an industrial control system (ICS) environment using the Modbus TCP protocol. The objective is to analyze communication patterns and detect anomalies related to potential attacks.

Scope

  • Simulate Modbus server (PLC-like behavior)
  • Analyze normal vs malicious communication
  • Simulate attacks (unauthorized write, traffic flooding)

Tools

  • Python (pymodbus)
  • Wireshark

Key Findings

  • Unauthorized write commands can manipulate system values
  • High-frequency requests indicate potential DoS behavior
  • Clear difference between normal and malicious traffic patterns

Skills Demonstrated

  • ICS/OT fundamentals
  • Network traffic analysis
  • Threat detection mindset
